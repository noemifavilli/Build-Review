# Build-Review
Written in Power Shell for the Cyber Passport training 

Build review script versions: 
- 0.1 finished on 20th October 2026
- 1.0 finished on 3rd November 2026


Most recent version: BuildReviewScript1-0.ps1


Useful CSV: 

BuildReviewResults.csv - for build review checks output 
- Displays the category of the check, the description, expected and actual value fetched, finally displays if the check passed/failed or requires review

OpenPorts.csv 
- Shows the open ports, the process name, ID, and when found, the address

ThirdPartyData.csv
- Displays all the installed third party applications on the target machine, including the name of the app, the version and publisher, and the installation date
